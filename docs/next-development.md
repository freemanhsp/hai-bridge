# 下一次开发任务：生命周期与诊断

安排日期：2026-11-21。代码基线：0.5.0 / 7236950；文档可能在其后单独提交，交付须记录实际HEAD/包哈希。本页列出尚未实现的任务，不规定后续项目管理工具。

## 目标与范围

让用户分清“本地停了、SSH停了、云端释放未核验”，并在普通退出及可捕获异常下可靠回收本次自有子进程。先完成本机实现与模拟回归；不用Windows配合，不执行真实模型调用，不修改ECS/VPN/MDM或网络路径。

不在本批实现自动续期、设备登记、后台守护、新中继协议或更多agent。Node被SIGKILL时无法依赖JS finally；报告限制而不是假装完全解决。

## P0-1：自有 SSH 清理

入口：src/tunnel.mjs、src/app-runtime.mjs、src/session.mjs；测试：test/tunnel.test.mjs、test/app-cli.test.mjs、test/session.test.mjs。

1. 先写最小失败测试：启动后回调/日志异常、退出中重复信号、SIGTERM不响应、close/error顺序、重连时旧child与新child竞争、timer在child已退出后触发。检查异步回调异常如何安全收敛，不把假设写成已复现bug。
2. 收敛owned-child停止/等待/超时逻辑：仅处理本调用持有的仍活跃child，TERM→有界等待→必要时KILL；finally异常退出也覆盖。解除旧timer/handler，防止退出后或重连后作用于错误进程。
3. 保留端口冲突不接管、致命认证/信任错误不重试、有界网络重连、取消传播和不重放POST行为。
4. 明确hard-kill/父进程死亡与远端半开是不同问题；只做无依赖可行性评估/实验，不偷偷加守护或系统自启动。只有证明安全且仍在用户范围内才另立实现批次。

验收：可捕获路径中自有SSH被回收，所有信号/计时器释放；旧child不影响新child/外部监听；错误保留安全退出码；默认测试从临时配置/端口运行，不能读取个人默认项启动实际SSH；npm test、npm run check及相关模块语法通过。

当前已知隔离修正：test/app-cli.test.mjs的缺省publisher错误测试显式指定不存在的临时profile-dir。新测试不得退回依赖“用户尚未setup”这一前提；CLI子进程测试尽量使用合成配置和SSH替身。

## P0-2：应用配置只读诊断与安全状态

入口：src/app-config.mjs、src/app-identity.mjs、src/app-status.mjs、bin/hai-bridge.mjs及现有preflight/report模块。

1. 先确定兼容入口：优先扩展明确的app-tls诊断模式，沿用旧doctor语义，不把旧离线SSH检查假装兼容应用配置。具体新参数/命令要在实现后才写到操作文档。
2. 离线检查配置/schema/角色、默认指针、Node/OpenSSH、文件元数据/Unix权限、公用CA与叶证书期限、预期本地端口。只读公开证书可用Node X509Certificate；不读HAI凭据，不输出token/私钥，不声称仅凭元数据证明密钥匹配。Windows ACL未查则明确not_checked。
3. 细分配置、端口、SSH认证/主机信任/转发冲突、TLS身份/到期、B bridge认证、A HAI认证与上游失败。当前可知道的原因与待在线检查原因分开；未知不能猜成过期或VPN问题。
4. 输出安全JSON摘要与短中文提示，区分本机停止、远端释放未核验；不打印原始stderr、认证headers、查询、提示词或回复。完整轮转/request日志另立后续批，不借诊断默认抓包。
5. 默认不发SSH/HTTP/模型请求；在线检查需明确选择，并仅用已有授权路径。远端占用输出检查步骤，不自动kill、改端口、删除known_hosts或放宽策略。

验收：有效/临期/过期/损坏证书与指针分别可判断；无网络/无HAI读取；敏感毒化输入不进报告；输出缺失项为未检查；正在运行的端口只提示，不结束进程；旧命令/JSON行为兼容。
